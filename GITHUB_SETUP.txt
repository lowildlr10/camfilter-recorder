HOW TO GET YOUR EXE AND RPM AUTOMATICALLY BUILT
================================================

GitHub Actions will build the Windows EXE, Fedora RPM, and macOS app
for you — no need to install anything locally.

STEP 1 — Create a GitHub repository
  1. Go to https://github.com/new
  2. Create a new repository (e.g. "camfilter-recorder")
  3. Upload the contents of this folder to the repo

STEP 2 — Trigger a build
  Option A — Build on every push (already enabled via workflow_dispatch):
    Go to your repo → Actions tab → "Build Installers" → "Run workflow"

  Option B — Create a release (recommended):
    git tag v1.0.0
    git push origin v1.0.0
    GitHub Actions will automatically build and attach the files to a release.

STEP 3 — Download your files
  Go to your repo → Actions → latest "Build Installers" run → Artifacts
    • CamFilterRecorder-windows  →  CamFilterRecorder.exe
    • CamFilterRecorder-fedora-rpm  →  CamFilterRecorder-1.0.0-1.fc40.x86_64.rpm
    • CamFilterRecorder-macos  →  CamFilterRecorder-macos.zip

INSTALLING THE RPM ON FEDORA
  sudo rpm -i CamFilterRecorder-1.0.0-1.fc40.x86_64.rpm
  # or
  sudo dnf install ./CamFilterRecorder-1.0.0-1.fc40.x86_64.rpm

  After install, find "CamFilter Recorder" in your app menu,
  or run:  CamFilterRecorder

UNINSTALLING THE RPM
  sudo dnf remove CamFilterRecorder
